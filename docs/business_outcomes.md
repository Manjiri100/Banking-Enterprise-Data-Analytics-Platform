# Expected analytical outcomes

The project is designed to answer four management questions:

1. **What is happening?** — transaction/payment volumes, values, failures and customer activity.
2. **Where is it happening?** — channel, region, product and segment breakdowns.
3. **Why is it happening?** — root-cause investigations using SQL and reconciliation checks.
4. **Can we trust the number?** — data-quality, lineage and source-to-report controls.

A strong final dashboard should prioritise actionable findings rather than simply displaying charts.
