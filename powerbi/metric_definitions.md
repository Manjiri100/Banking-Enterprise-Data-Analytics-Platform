# KPI definitions

| KPI | Definition |
|---|---|
| Transaction volume | Count of valid transaction IDs |
| Completed value | Sum of amount where transaction status = completed |
| Payment failure rate | Failed payments / total payments |
| High-risk alerts | Fraud alerts with risk score >= 75 |
| Complaint backlog | Complaints not in resolved status |
| Reconciliation variance | Finance-side completed value minus settlement value |
| Active customers | Distinct customers with active customer status |
