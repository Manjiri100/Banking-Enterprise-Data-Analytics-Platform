# Portfolio story

This project is intentionally built around a business problem rather than a technology checklist.

A banking organisation has fragmented operational data and needs trusted MI. The analyst must first determine whether the data is reliable, reconcile conflicting numbers, investigate operational changes, then create a governed analytical model and dashboard.

The portfolio demonstrates that sequence end-to-end: **business request → data profiling → quality issue → investigation → transformation/model → dashboard → conclusion**.
